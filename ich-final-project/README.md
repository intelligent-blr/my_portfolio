# CRM & Product Analytics – Online-Programmierschule X

Abschlussprojekt der Weiterbildung (ITCareerHub). Analyse von CRM-Daten einer Online-Programmierschule: Vertrieb, Marketing und Produktperformance.

## Vorgehen
1. **Bereinigung:** Duplikate, irrelevante Spalten, fehlende Werte, Datentypen
2. **Deskriptive Statistik:** Lead-Qualität, Vertriebsphase, Quelle, Produkt
3. **Zeitreihen:** Deals über die Zeit, Dauer bis Abschluss, Zusammenhang mit Anrufen
4. **Kampagnen und Vertrieb:** Conversion Rate, Umsatz, Sales-Owner im Vergleich
5. **Zahlungen, Produkte, Regionen:** Erfolgsquote nach Zahlungsart, Produkt, Stadt, Deutschniveau
6. **Product Analytics:** Unit Economics je Produkt, Metriken-Baum, Hypothesen (Tests max. 2 Wochen)
