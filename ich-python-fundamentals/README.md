# Filmsuche mit Python & SQL

Interaktive Konsolenanwendung zur Suche in der Sakila-Beispieldatenbank. Suchanfragen werden in einer separaten Datenbank gespeichert und nach Häufigkeit ausgewertet.

## Funktionen
- Suche nach Schlüsselwort
- Suche nach Genre und Erscheinungsjahr
- Anzeige der beliebtesten Suchanfragen

## Aufbau
- `db`-Modul: Datenbankzugriff und SQL-Abfragen
- `ui`-Modul: Benutzerinteraktion
- `output`-Modul: Darstellung der Ergebnisse
